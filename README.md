# Exoole
![Exoole](screenshot.png)

Exoole is a modern page builder for WordPress, with a primary focus on Gutenberg. It provides a seamless and intuitive experience for creating beautiful web pages.

## Features

- **Gutenberg Integration**: Fully compatible with the Gutenberg editor, making it easy to build and customize pages.
- **Modern Design**: Sleek and contemporary design elements to enhance your website's appearance.
- **User-Friendly**: Simple and intuitive interface for users of all skill levels.

## Installation

1. Download the Exoole plugin.
2. Upload the plugin files to the `/wp-content/plugins/exoole` directory, or install the plugin through the WordPress plugins screen directly.
3. Activate the plugin through the 'Plugins' screen in WordPress.

## Usage

1. Navigate to the Gutenberg editor.
2. Start building your page using Exoole's custom blocks and features.
3. Customize the design and layout to match your brand.
